# 關卡編輯器(本機伺服器)

```bash
npm run editor      # 開啟 http://localhost:5180/editor.html
```

本機開發工具:用 Vite 伺服器提供編輯器網頁,加上一個 JSON API(`tools/level-editor/levelApi.ts`),直接讀寫專案裡的關卡檔(只限 `src/levels/builtin/` 之內)。改完後遊戲的 dev server 會直接看到;App 要重新打包(`npm run android:apk`)。

## 畫面

- **左側:關卡列表**。依來源分組:教學關卡、編輯器關卡、各 World 的生成關卡、社群關卡、舊生成關卡。有搜尋。
- **中間:目前的房間**。用遊戲本身的繪圖程式畫,箱子內部會遞迴顯示。有格線、游標所在格、選取框、座標。上方的麵包屑顯示目前在哪個房間,點一下可以回到外層。**雙擊有內部的箱子可以進入編輯**。
- **右側:工具 + 屬性**。
  - 地形:選取、地板、牆、清除。
  - 目標:箱子目標、玩家目標。
  - 物件:玩家、實心箱、箱中箱(可設定新房間大小)、自包箱、分身/引用(通往已存在的房間)、∞ 箱(可選層數)、可附身箱、可附身牆。
  - 屬性面板:
    - 物件:種類、通往哪個房間、顏色、fliph、exitblock、可附身、牆方塊、∞ infexit(層數)、ε infenter(層數、id),以及「玩家也是箱子」。
    - 房間:大小、顏色、漂浮 floatinspace。
    - 關卡:attempt_order。
- **下方分頁**:
  - **求解**:最短解、搜尋量、耗時。可以逐步預覽解法(拖曳滑桿或點箭頭,中間畫面顯示那一步,不能編輯)。
  - **World 分類驗證**:對每個 World 做三層驗證(存在 / 使用 / 必要)。「編輯器關卡」存檔後,可以把通過的關卡放入該 World,之後遊戲的關卡列表會把它列在那個 World 的生成關卡之後。
  - **官方格式**:目前關卡轉成官方 `.txt`(可以下載);貼上或讀取 `.txt` 匯入成新關卡。
- **上方**:新增、保存(Ctrl+S)、另存新關卡、復原/重做(Ctrl+Z / Ctrl+Y)、試玩(全螢幕,用遊戲本身的畫面)、刪除關卡。
- **刪除關卡**:在列表中把游標移到關卡上會出現 🗑,或按上方的「删除关卡」。會刪除檔案,並從清單移除(編輯器關卡清單、World 清單)。教學關卡是遊戲程式直接引用的,不能刪。

## 操作

- 左鍵:使用目前工具。地板、牆、清除、箱子目標可以拖曳連續畫。
- 右鍵:清除該格。
- 雙擊有內部的箱子:進入它的房間。
- 快捷鍵:V 選取、F 地板、W 牆、E 清除、B 箱子目標、G 玩家目標、P 玩家、1~7 各種物件、Esc 結束預覽或取消選取。
- 狀態列會即時檢查關卡結構(例如必須只有一個玩家、房間都要連得到)。有問題時不能保存,也不能試玩。

## 新增關卡(重新設計)

對話框有三種起點:

1. **圍牆房間**:四周是牆的空房間。
2. **空房間**:全部都是地板。
3. **World 草稿**:選一個 World,生成器產生一個**已通過該 World 三層驗證**的關卡作為起點(最多 20 秒)。

可以設定名稱、大小(3–15)和最外層顏色。

## 存到哪裡

| 來源 | 保存行為 |
|---|---|
| 新關卡 / 另存新關卡 | `src/levels/builtin/authored/<名稱>.json`,並寫入 `authored/manifest.json`(名稱、放入的 World) |
| 教學關卡 | 直接覆寫原檔 |
| World 生成關卡 | 覆寫原檔。**重新執行 `generate:worlds` 會蓋掉修改**,保存前會再確認一次 |
| 社群關卡 | 覆寫轉換後的 `.json`。**重新轉換 `.txt` 會蓋掉修改** |

編輯器關卡放在 `authored/`,重新生成關卡不會影響它們。

## 程式

- `src/level-editor/editOps.ts`:純函式的編輯操作,不假設最外層叫 `root`,任何現有關卡都能編輯。刪除物件後,不再連得到的房間(和裡面的東西)會自動清掉;會刪掉玩家的操作一律拒絕。
- `src/level-editor/tools.ts`:工具定義與套用。
- `src/game/engine/officialExport.ts`:完整的官方格式匯出,是 `parseOfficialLevel` 的反向操作,用 8 個社群關卡做「匯入→匯出→匯入」來回測試。
